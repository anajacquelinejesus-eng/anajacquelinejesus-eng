## Projeto em destaque

### ERB Monitoring Pipeline

Pipeline de Engenharia de Dados desenvolvido utilizando **dados reais da ANATEL**.

O projeto simula um cenário de ingestão, processamento e armazenamento de dados, utilizando tecnologias presentes em arquiteturas modernas de dados.

**Stack**

`Python` `PostgreSQL` `Apache Kafka` `Docker` `PySpark`

**Principais entregas**

* Ingestão de dados reais da ANATEL
* Tratamento e processamento de dados
* Estruturação de pipeline ETL
* Armazenamento em PostgreSQL
* Streaming e mensageria com Kafka
* Ambiente containerizado com Docker
* Estrutura preparada para monitoramento e análise
