## Projeto em destaque

### DataShop — Pipeline de Dados de E-commerce

Projeto de Engenharia de Dados que simula o processamento de dados de um e-commerce, cobrindo diferentes etapas do ciclo de dados.

**Principais entregas:**

* Modelagem de banco de dados relacional
* Criação de tabelas com chaves primárias e estrangeiras
* Consultas analíticas com JOINs, CTEs e Window Functions
* Pipeline ETL desenvolvido com Python e Pandas
* Tratamento de duplicatas, valores nulos e inconsistências
* Carga de dados no PostgreSQL
* Ambiente reproduzível com Docker Compose
* Orquestração e agendamento com Apache Airflow

**Tecnologias:** SQL, PostgreSQL, Python, Pandas, Docker e Apache Airflow.

[Ver projeto DataShop](https://github.com/anajacquelinejesus-eng/datashop-sql)
