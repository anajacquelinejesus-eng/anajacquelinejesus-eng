## Projeto em destaque

### 🛒 DataShop

Pipeline de dados de um e-commerce, desenvolvido para praticar diferentes etapas da Engenharia de Dados.

**Principais entregas:**

* Banco relacional em PostgreSQL
* Consultas com JOINs, CTEs e Window Functions
* Pipeline ETL com Python e Pandas
* Tratamento e limpeza de dados
* Ambiente com Docker Compose
* Orquestração com Apache Airflow
